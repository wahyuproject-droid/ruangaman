Lapor dan cek laporan.

Suarakan yang terjadi. Simpan nomor laporanmu untuk melihat perkembangannya.

FORMULIR / PENGADUAN

Ceritakan dengan aman.

Untuk pengalaman atau kejadian perundungan di sekolah. Kamu tidak wajib menyebutkan nama. Ceritakan seperlunya, dan jangan memasukkan kata sandi atau data pribadi orang lain.

Penting: Laporan dinyatakan terkirim hanya setelah muncul ID RM-.... Simpan ID untuk mengecek status. Jika belum mendapat ID, laporan belum terkirim. Untuk bantuan segera, hubungi guru BK, wali kelas, atau orang dewasa tepercaya.
Minimal 20, maksimal 3.000 karakter. Hindari mencantumkan nama lengkap jika tidak diperlukan.
Laporan berhasil diterima server.

Simpan ID ini secara pribadi. Status awal: Diterima. Laporan bukan layanan darurat.

CEK / STATUS

Lacak dengan ID RM-

Masukkan ID rahasia RM-... untuk melihat status dan waktu pembaruan. Isi kronologi tidak akan ditampilkan.

STATUS LAPORAN

    Jaga kerahasiaan ID. ID laporan bersifat rahasia: siapa pun yang memiliki ID dapat melihat status saja. Jangan membagikannya ke publik.
